# Week 02 Answers

`bill-splitter/index.html` completes Tasks 1 and 2: enter menu item names and costs, select 0/5/10/15/20% tip and number of people, then calculate subtotal, tip, total and equal share. Validation messages are styled in CSS. JavaScript and CSS are external files.

`todo/index.html` completes Task 3. Add tasks and tick completed items. No data is saved, so refresh clears the list.
