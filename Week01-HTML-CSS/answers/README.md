# Week 01 Answers

## W3Schools tutorial notes
**CSS Navigation Bars:** Usually made from a list of links. CSS removes bullets, adds spacing, controls horizontal/vertical layout and hover styles.

**CSS Website Layout:** A standard layout contains a header, navigation, main content, columns and footer. Flexbox and Grid are useful for arranging content.

**Responsive Web Design:** Use the viewport meta tag, flexible widths, responsive images (`max-width:100%`) and media queries. On narrow screens, columns can change to one column.
